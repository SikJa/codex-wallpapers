# Procedencia y derechos

El empaquetado, biblioteca, runtime, selector y lanzador de este repositorio se desarrollaron para este proyecto. No se incluye el inyector de Dream Skin ni un motor Liquid Metal. El runtime conserva únicamente el concepto y los ajustes de apariencia solicitados para wallpapers.

Se utilizan APIs estándar del navegador, Node.js, Windows COM y el protocolo de depuración de Chromium/Electron. Los selectores del DOM se adaptan a una versión de Codex y pueden cambiar.

Codex y sus iconos pertenecen a OpenAI. El instalador obtiene el icono de la copia local; no se distribuye en este repo. Wallpaper Engine, Steam y los fondos de sus creadores mantienen sus marcas y licencias. FFmpeg y Playwright son herramientas externas, no se redistribuyen aquí.
